# Data

The datasets used in this study are available through the following Google Sheets:

- [Dataset 1] – Sheet dataset containing information on recovered and redeployed Argo floats, including float characteristics, recovery history, operational outcomes and associated recovery costs, such as transportation, customs, repair and sensor recalibration.(https://docs.google.com/spreadsheets/d/1Q31XUWQHcJaewqIk-uTvTAZuTOE8-tFwOZA7F9RuEzo/edit?usp=sharing)
- [Dataset 2 – Sheet dataset inventory of Argo floats compiled from the beginning of the Argo programme to the present, including deployment, mission, technical, recovery and redeployment metadata.](https://docs.google.com/spreadsheets/d/1NuiaY9RBKX8bIEqAwItuMc9vc4uGlO71/edit?usp=sharing&ouid=117281156118505542397&rtpof=true&sd=true)
- [Dataset 3 – Argo Float Recovery Assessment Tool (ARAT), an Excel-based decision-support tool for assessing float condition and supporting recovery, refurbishment, redeployment and valuation decisions.](https://docs.google.com/spreadsheets/d/1GRXhHZgf-vm2XZWb8W2v8vwrTUnesX-X/edit?usp=sharing&ouid=117281156118505542397&rtpof=true&sd=true)

These datasets provide the input data used in the analyses presented in the manuscript.
