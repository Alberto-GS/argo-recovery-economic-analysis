# Data

The datasets used in this study are available through the following Google Sheets:

1) Dataset containing information on recovered and redeployed Argo floats, including float characteristics, recovery history, operational outcomes and associated recovery costs, such as transportation, customs, repair and sensor recalibration. [Dataset 1](https://docs.google.com/spreadsheets/d/1Q31XUWQHcJaewqIk-uTvTAZuTOE8-tFwOZA7F9RuEzo/edit?usp=sharing)
2) Compiled inventory of Argo floats compiled from the beginning of the Argo programme to the present, including deployment, mission, technical, recovery and redeployment metadata. [Dataset 2](https://docs.google.com/spreadsheets/d/1NuiaY9RBKX8bIEqAwItuMc9vc4uGlO71/edit?usp=sharing&ouid=117281156118505542397&rtpof=true&sd=true)
3) Argo Float Recovery Assessment Tool (ARAT), an Excel-based decision-support tool for assessing float condition and supporting recovery, refurbishment, redeployment and valuation decisions. [Dataset 3](https://docs.google.com/spreadsheets/d/1GRXhHZgf-vm2XZWb8W2v8vwrTUnesX-X/edit?usp=sharing&ouid=117281156118505542397&rtpof=true&sd=true)

These datasets provide the input data used in the analyses presented in the manuscript.
